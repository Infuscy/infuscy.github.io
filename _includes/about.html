Despre

Acest site gazduieste investigatii de date statice despre rezultatele Bacalaureatului. Fiecare raport ruleaza complet in browser — zero backend, zero server propriu.

Datele sunt preluate de pe site-ul oficial al Bacalaureatului, agregate cu Python si PyArrow, si vizualizate cu React, Recharts si Leaflet. Majoritatea rapoartelor includ si un consolator SQL live peste setul complet de date.
